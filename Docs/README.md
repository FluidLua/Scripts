## Loader
* Loads the proper script for a game if it's configured. Universal fallback if no script is configured for the game
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/FluidLua/Scripts/main/Loader.lua"))()
```

## Remote Spy
* Detectable in some games, also might be broken more then usual
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/FluidLua/Scripts/main/RemoteSpy.lua"))()
```
